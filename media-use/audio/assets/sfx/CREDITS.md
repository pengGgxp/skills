# Excluded SFX Assets

This adapted copy of `media-use` does not redistribute the 19 MP3 files or their manifest from upstream HyperFrames `v0.7.55`.

Upstream describes the files collectively as Pixabay content, but does not record a work title, creator, or source URL for each file. The [Pixabay Content License](https://pixabay.com/service/license-summary/) also restricts distributing content on a standalone basis. A portable Skill bundle would redistribute the original audio files rather than a rendered derivative, so the available provenance is not sufficient for this repository.

Use the HeyGen catalog path, or pass `--sfx-lib <dir>` with audio files whose license and provenance you have verified. No audio file in this directory is covered or redistributed by this notice.
