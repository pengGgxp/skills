# AI Writing Patterns

把模式当成诊断线索，而不是禁词表。单个词或句式不能证明“AI 味”；真正的问题是它在文章中反复承担了错误功能。

## 四个层面

### 1. 词句层

| 信号 | 实际问题 | 修复方向 |
| --- | --- | --- |
| “值得注意的是”“不难发现”“总体而言”反复出现 | 作者没有决定什么真正值得注意 | 直接写事实和判断，或删除提示语 |
| “具有重要意义”“带来深远影响” | 重要性没有落到具体对象和后果 | 说明谁会因此改变什么决定 |
| “有观点认为”“业内普遍认为” | 来源和责任模糊 | 给出来源，或改成作者可承担的判断 |
| 连续使用“可能、或许、一定程度上、相对” | 判断被多层保护 | 校准一次范围，保留真正必要的不确定性 |
| 高频“不是 A，而是 B” | 用句式制造洞察感 | 只有存在真实误判和证据时保留，否则直接说 B |

### 2. 节奏层

- 句子长度接近，段落都由三四句组成；
- 每段都先判断、再解释、最后小结；
- 信息密度从头到尾完全一致；
- 连续三段以上使用相同起句和收句方式。

不要随机打碎句子来“增加熵”。根据内容重量改变节奏：关键机制展开，明确事实短写，真正转折留出停顿。

### 3. 结构层

- 标题、导语、摘要表、章节结尾和结论反复给出同一答案；
- 所有章节数量、长度和内部结构过度对称；
- 章节可以任意交换；
- 每个判断后立即跟一个同等重量的反方段落；
- 开头先讲宏大背景，结尾再讲趋势、机会与挑战。

这类问题不能靠逐句润色解决。回到文章脊柱，重新决定哪些材料负责证明、解释、限制和落地。

### 4. 编辑意图层

- 作者只整理资料，不做取舍；
- 每句话都在避免被反驳，整篇却没有要争取的判断；
- 正文展示搜索、核验和审核过程，而不是读者需要的结果；
- 文章可以替换产品名后用于任何同类对象；
- 结尾只表示“未来值得持续关注”。

这是最强的“AI 味”来源。修复它需要重新选择观点和材料，而不是增加口语词。

## 常见错误修法

不要：

- 批量替换高频连接词；
- 强行加入“说实话”“其实”“我觉得”；
- 随机插入短句、破折号、反问或感叹；
- 编造第一人称体验来制造真实感；
- 为通过检测器循环改写；
- 把所有限定条件删掉，换取表面上的果断；
- 把一篇清楚的人类稿件改造成统一的“自然文风”。

应当先问：这段增加了什么？如果答案只是“显得严谨”“保持平衡”或“连接上下文”，优先改变其功能或删除。

## 独特性测试

做三项快速检查：

1. 替换测试：换掉产品名、人物名或行业名后，段落是否仍可原样使用？
2. 结尾测试：把结尾放到另一篇同主题文章后，是否仍然自然？
3. 决策测试：文章是否做出了至少一个由证据支持、也可能被读者质疑的明确取舍？

前两项为“是”或第三项为“否”时，优先重建编辑意图。
