# Habit Diagnosis

Use this after cleaning. Keep suggestions short and tied to scan results.

## If Downloads Is Large

Say: "下载目录是大头。以后安装包、压缩包用完就删，下载位置可以改到 D 盘。"

Give only a few examples: `.exe`, `.msi`, `.zip`, `.rar`, `.7z`, `.iso`.

## If Desktop Is Large

Say: "桌面放了很多大文件，桌面本质上也在 C 盘。建议把大文件移到 D 盘，只留快捷方式。"

## If WeChat Or QQ Is Large

Say: "微信/QQ 文件占用明显。建议先在软件设置里把文件保存位置改到 D 盘，再整理旧聊天文件。"

Do not promise that moving the folder manually is safe. Prefer app settings.

## If Many Apps Are Installed On C

Say: "很多软件装在 C 盘，清理后还会慢慢涨。以后新软件安装时选择 D 盘，例如 `D:\Apps`。"

Do not advise moving installed program folders manually. Use app uninstall/reinstall or app-provided migration.

## If Browser Cache Is Large

Say: "浏览器缓存清完会重新生成，这是正常现象；它适合清理，但不是长期根治。"

## If Virtual Disks Or Developer Caches Are Large

Say: "这类文件不是垃圾。Docker、WSL、虚拟机、开发缓存要按对应工具迁移，不能直接删。"

Mention this only when scan results reveal such files or the user says they use development tools.

## Keep The Ending Small

End with at most three prevention tips. Choose the most relevant ones by size. Avoid generic long checklists.
